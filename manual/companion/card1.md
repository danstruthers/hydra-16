# Card 1. Keys

### Typing a line (section 6.3)

| Keys | What they do |
|---|---|
| <kbd>RETURN</kbd> | Send the line |
| <kbd>BACKSPACE</kbd> | Rub out the letter before the cursor |
| <kbd>←</kbd> <kbd>→</kbd> | Move along the line |
| <kbd>HOME</kbd> or <kbd>CTRL</kbd>-<kbd>A</kbd>, <kbd>END</kbd> or <kbd>CTRL</kbd>-<kbd>E</kbd> | The start of the line; its end |
| <kbd>CTRL</kbd>-<kbd>U</kbd> | Rub out the whole line |
| <kbd>↑</kbd> <kbd>↓</kbd> | Bring back the lines typed before |

### At any time

| Keys | What they do |
|---|---|
| <kbd>CTRL</kbd>-<kbd>C</kbd> | Stop the program that's running |
| <kbd>CTRL</kbd>-<kbd>D</kbd> | At the start of a line: "that's the end of my typing" |
| <kbd>CTRL</kbd>-<kbd>]</kbd> | The window key: then one of the keys below |

### The window key, <kbd>CTRL</kbd>-<kbd>]</kbd>, and then (section 10.3)

| Key | What it does | Key | What it does |
|---|---|---|---|
| <kbd>C</kbd> | A new group, with a shell | <kbd>W</kbd> | The list of windows |
| <kbd>0</kbd> to <kbd>9</kbd> | Show that window | <kbd>?</kbd> | The window keys |
| <kbd>TAB</kbd> | The group's next window | <kbd>N</kbd>, <kbd>P</kbd> | The next group; the one before |
| An arrow | The window that way | <kbd>X</kbd> | Close the group shown |

### Where am I? (section 6.4)

| The prompt | Who's listening | To get back |
|---|---|---|
| `/>` | HyForth, the shell | |

### In the screen editor, `edit` (Chapter 11)

| Keys | What they do | Keys | What they do |
|---|---|---|---|
| <kbd>CTRL</kbd>-<kbd>O</kbd>, <kbd>RETURN</kbd> | Save | <kbd>CTRL</kbd>-<kbd>K</kbd> | Cut the line |
| <kbd>CTRL</kbd>-<kbd>X</kbd> | Close the file, and leave | <kbd>CTRL</kbd>-<kbd>U</kbd> | Paste |
| <kbd>CTRL</kbd>-<kbd>G</kbd> | Show all the keys | <kbd>ESC</kbd> <kbd>U</kbd> | Undo |
| <kbd>CTRL</kbd>-<kbd>W</kbd> | Find | <kbd>ESC</kbd> <kbd>G</kbd> | Go to a line |
| <kbd>CTRL</kbd>-<kbd>R</kbd> | Open another file | <kbd>ESC</kbd> <kbd>R</kbd> | Find and replace |

### In the emulators (Chapter 2, Appendix H)

| Keys | What they do |
|---|---|
| <kbd>CTRL</kbd>-<kbd>A</kbd> then <kbd>X</kbd> | The terminal emulator, and the PC tool: quit |
| <kbd>CTRL</kbd>-<kbd>A</kbd> then <kbd>R</kbd> | The terminal emulator: press reset |
| <kbd>CTRL</kbd>-<kbd>A</kbd> twice | Send a real <kbd>CTRL</kbd>-<kbd>A</kbd> to the Hydra |
| <kbd>CTRL</kbd>-<kbd>SHIFT</kbd>-<kbd>V</kbd> | The web emulator: paste |
