# Part Three. Projects

A project is bigger than a lab: a program to type in and get going, and then to make your own. Each one starts
with a listing that works. What you turn it into is up to you.

Take a project when you've done the labs it names. Each ends with a list of things to show when you've finished:
a project isn't done until someone else has seen it run.
