# Part Three. Devices

The Hydra's devices, and the drivers that look after them: the console and the terminal, the disks, sound, the Vera
X's screen, keyboard and mouse, and the rest. Each chapter lists every file a driver gives you, and every command
its control files understand.

The examples in this part are single lines typed at the shell. Some are HyForth and some are rc, and you can type
them all just as they're printed, without knowing either language. If you'd rather learn a language first, read
Part Four now and come back: the second chapter of each language shows how to work these same devices from a
program.
