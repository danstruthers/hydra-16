# Part Four. Programming Languages

The Hydra has three programming languages built in: **HyForth**, **hylang** and **HyBASIC**. This part starts with
the numbers they all share, then teaches each language in two chapters: the first for learning it, the second for
using it to work the Hydra's devices, files and sound. Appendices A, B and C are each language's complete reference.

* Chapter 19. Learning HyForth
* Chapter 20. Programming the Hydra in HyForth
* Chapter 21. Learning hylang
* Chapter 22. Programming the Hydra in hylang
* Chapter 23. Learning HyBASIC
* Chapter 24. Programming the Hydra in HyBASIC
