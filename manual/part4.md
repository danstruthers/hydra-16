# Part Four. Programming Languages

The Hydra has three programming languages built in: **HyForth**, **hylang** and **HyBASIC**. This part starts with
the numbers they all share, then teaches each language in two chapters: the first for learning it, the second for
using it to work the Hydra's devices, files and sound. The last chapter writes one program in all three, side by
side. Appendices A, B and C are each language's complete reference.

**Which language first?** If you've never programmed, start with **HyBASIC** (Chapter 23): it reads almost like
English. **HyForth** (Chapter 19) is the Hydra's shell, so it's the one you'll use every day, and it's the best
way to feel how a small computer works. **hylang** (Chapter 21) has the most powerful ideas, and suits people who
like mathematics and lists. You don't have to learn all three, and you can read each language's two chapters without
the others'. Whichever you choose, read sections 18.1 to 18.3 first: all three count the same way.
