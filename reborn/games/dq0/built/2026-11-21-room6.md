## 3. The D17 band (items 1 and 2, and the coordinator's band)

### How it was measured

A profiler hook for the tests (not committed: base/sim/test.js and machine.js patched in the scratch only): the
cycles of every instruction in one line's window, from its Enter to its first letter, by task and by C function (the
runtime's helpers charged to the C function that called them, by the return addresses on the 6502's stack), and each
part copied into a swap area (swload) with its cycle. The windows are exact: a run is the same, cycle for cycle, each
time at one build.
