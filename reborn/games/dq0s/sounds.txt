# sounds.txt - (dq0s) the sounds (SOUND.md): each kind's (the denizens' kinds, dq0d/kinds.txt, by key), and the
# world's, as the character hears them and the chips play them; a stand-in theme's, as the kinds are.  make.js makes
# it the sound task's data file (lib/dq0/dq0s.dat: 32 bytes a sound: each kind's two in kinds.txt's order, the first
# none, then the world's), which it puts in the hub (SND_AT) as it starts: the UI words what's heard by it too.
#
# A line a sound, its fields between bars:
#   key       a kind's (kinds.txt's), or the world's own: *dig, *open, *shut, *blow, *smash, *chains, *trap
#   act       a kind's: step (a step, a dash), noise (a noise of its own); the world's: -
#   words     what the character hears it as, its article first (19 letters at most: "a scurrying"), or - none
#   ym        the YM2151's: d N, General MIDI's drum N (35 kick ... 81 open triangle); or P N, patch P (0-162: the
#             driver's) at MIDI note N
#   psg       the Vera X's PSG's: a waveform (p pulse, s saw, t triangle, n noise), its width (0-63, a pulse's), a
#             MIDI note (noise too: its pitch); a noise is played on the PSG first, with a Vera X
#   hits      how many, and the ticks (200 a second) from one's start to the next's: N-T
#   hold      ticks each hit is held
#   level     how loud at its loudest, 0-127 (the chips' level, as heard from beside it)
#
