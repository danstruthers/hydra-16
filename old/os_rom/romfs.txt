; ****************************************************************************
; The /rom file system: the files on the ROM disk, a HydraFS volume in the paged ROM from bank 2 (hfs's x,
; which the boot shell mounts at /rom: mount hfs /rom x).  sim/tools/mkromdisk.js makes it, after the link (build.js), and checks each
; file read back from the image.  A line per file: its path in /rom, then its source (relative to this folder).
; /rom/bin and /rom/lib are the last members of /bin and /lib (lib/namespace), where the shell looks for programs
; and HyForth libraries, so these run with no card at all.
